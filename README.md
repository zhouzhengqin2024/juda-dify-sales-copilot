# 据答｜企业 AI 客服售前核对 Demo

[在线试用](https://enterprise-service-fit.allen808.chatgpt.site) · 虚构产品资料 · 模拟价格 · 非正式方案

输入客户原话，工作流提取需求并判断业务范围，再检索模拟产品资料、逐项核对能力与限制。需要试算且文字明确给出专业版和唯一坐席数时，使用独立模拟价格表计算软件年费。缺少证据的功能、工期和费用保留为待确认，不由模型编造。流程还包含方案草稿、人工审核与模拟客户机会记录节点。

## 仓库内容

| 路径 | 内容 |
| --- | --- |
| `app/`、`db/`、`drizzle/` 等 | React/Vinext 前端、Cloudflare Worker 接口及 D1 限流数据表 |
| `dify/workflow.yml` | Dify 导出的 15 节点工作流 DSL；已移除 HTTP 节点中的真实凭据 |
| `pricing/prices.json` | 演示价格表快照，专业版 1–50 坐席，600 元/坐席/年；不含部署、接口开发、维护 |

## 调用链

客户需求 → 网站服务端限流 → Dify 工作流 → 需求提取与范围判断 → 产品资料检索与逐项核对 → 模拟价格表与确定性计算 → 报告。工作流另设人工审核和模拟机会记录分支。

网站 API 位于 `app/api/analyze/route.ts`。Dify API Key 只在服务端环境变量 `DIFY_API_KEY` 中读取；DeepSeek 模型凭据只在 Dify 模型供应商设置中配置。两者均未写入本仓库。

## 运行和迁移

1. 安装 Node.js 22.13+，执行 `npm ci` 和 `npm run build`。
2. 为自己的部署配置 D1 绑定 `DB`，应用 `drizzle/` 迁移，并在服务端配置 `DIFY_API_KEY`。`.openai/hosting.json` 中的项目 ID 指向作者的在线演示；新部署需使用自己的项目。
3. 将 `dify/workflow.yml` 导入自己的 Dify 工作区，重新选择模型供应商、知识库和检索节点。**DSL 不包含知识库文档或供应商凭据**，导入后不能直接得到同样的检索结果。
4. 价格表的实际 HTTP 地址是独立演示服务。`pricing/prices.json` 只是数据快照；如需独立复现，请将其托管为可读取的 JSON，并修改工作流的“获取模拟报价表”节点地址。
5. “保存模拟客户机会”节点的 `Authorization` 已替换为 `YOUR_MOCK_OPPORTUNITY_API_KEY`。若使用自己的模拟记录服务，请配置自己的地址与密钥；当前仓库不包含该服务的写入实现。

## 试用边界

- 网站接口按公网 IP 限制每小时 5 次，整个 Demo 一个 24 小时额度周期内最多 50 次；超过时在调用 Dify 前返回 HTTP 429。共用出口 IP 的用户共用额度。原 Dify 分享页若仍公开，不受网站限制。
- 试用弹窗提示模拟资料、模拟报价及额度；它负责告知，真正限流发生在服务端。
- 范围判断仍需要先运行提取节点，因此无关需求也可能消耗一次模型调用。IP 变化或直接访问 Dify 分享页也可能绕过网站的单 IP 限制。
- 价格表只覆盖明确要求按专业版、人数唯一且在 1–50 坐席内的软件年费；它不证明整体需求能满足，也不是正式报价。
- 请勿提交真实客户或敏感信息。本项目用于展示需求分析、RAG 证据核对、确定性报价计算和人工审核流程，不代表可直接投入生产。

## 验证

前端通过 TypeScript 类型检查和 ESLint；公开站点对同一网络地址的前 5 次请求正常处理，第 6 次返回 HTTP 429。产品案例覆盖基础/专业/企业版、缺少资料的渠道和 SLA、部署边界、预算与无关业务分流。导出的 DSL 解析后保留 15 个节点，公开文件里的模拟机会请求头仅保留密钥占位符。
